📸 1. 구글 드라이브 사진첩 & 시트 통합 코드

아래 통합 스크립트를 붙여넣으면 ① 하객이 올린 사진은 내 구글 드라이브의 이지후_고우진_결혼식_하객스냅 폴더에 자동 저장되어 청첩장 갤러리에 실시간 표시되고, ② 참석 의사(RSVP)는 구글 시트에 자동 기록됩니다.

  1. 새 구글 스프레드시트를 열고 상단 메뉴 [확장 프로그램] → [Apps Script]를 클릭합니다.
  2. 기존 코드를 지우고 위 [Apps Script 코드 복사] 버튼으로 복사한 코드를 붙여넣은 뒤 저장(💾)합니다.
  3. 우측 상단 [배포] → [새 배포] 클릭 → 유형: 웹 앱(Web App), 다음 사용자 권한으로 실행: 나(Me), 액세스 권한: 모든 사용자(Anyone)로 설정 후 배포(권한 승인)합니다.
  4. 발급된 웹 앱 URL (https://script.google.com/macros/s/.../exec)을 아래 입력창 또는 코드의 WEDDING_CONFIG.googleScriptUrl에 붙여넣으면 완료됩니다!
